## Getting started

1. Open **Start**, type `cmd`, and press **Enter**.
2. Find a command in the handbook.
3. Read its purpose and notes before running it.
4. Type or paste one command at a time, then press **Enter**.

## Safety first

- Read commands before running them, especially commands that delete, format, repartition, or change settings.
- Do not run unfamiliar commands copied from the internet.
- Some diagnostic and repair commands require **Run as administrator**.
- Commands that change network settings can temporarily disconnect you.
- Back up important files before disk repairs or system changes.

## Compatibility note

Some older examples use WMIC. WMIC is deprecated and may be absent on newer Windows versions. Use **Task Manager**, **System Information** (`msinfo32`), **DirectX Diagnostic Tool** (`dxdiag`), or PowerShell alternatives if a WMIC command is unavailable.
